# Dashboard V2

The dashboard layer has been redesigned for the healthcare platform rather than the old marketplace.

## Doctor / Chamber
- Removed marketplace concepts such as stock, orders, product status and product charts.
- Replaced the home dashboard with a compact healthcare overview: appointments, doctor profiles, views, saves and verification.
- Added three clean action cards: personal information, chamber/hospital and website.
- Kept the first three mobile menu items as requested: Personal Information, Chamber, Website.
- Reduced the main navigation to essential healthcare actions.

## Admin / Super Admin
- Removed marketplace wording and marketplace analytics charts from the main dashboard.
- Dashboard now focuses on doctors, chambers/hospitals, patients, pending verification, volunteer blood donors and ambulances.
- Added compact quick-management cards.
- Super Admin gets a small dedicated control block for role/access management instead of a large analytics wall.
- Sidebar switched to a lighter, cleaner medical-dashboard style.

No new SQL is required for Dashboard V2.
